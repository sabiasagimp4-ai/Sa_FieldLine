# YMM4 本実装の設計メモ

プロトタイプ（`prototype/fieldline.py`）で確定した挙動を Direct2D カスタムエフェクトへ移植するための計画。
Sa_chromablur と同じ構成（`IVideoEffectProcessor` + `D2D1CustomShaderEffectBase` + fxc でビルドした `.cso` を埋め込み）を踏襲する。

## 単一パスでは無理なので、パスを分ける

プロトタイプは「広域拡散 → 場の確定 → 流線積分」の 3 段階で、
それぞれ必要な近傍サイズが違う。1 枚のピクセルシェーダには収まらないので、
`Processor` 側で複数のカスタムエフェクトと D2D 組み込みエフェクトを繋ぐ。

| パス | 解像度 | 入力 | 出力 | 内容 |
| --- | --- | --- | --- | --- |
| P0 | 1/4 | 元画像 | 輝度 | `D2D1Scale` で縮小 + 輝度化。場は滑らかなので 1/4 で十分（負荷 1/16） |
| P1 | 1/4 | P0 を σ, 2σ, 4σ, 8σ でぼかしたもの | RG=conf·n, B=conf | 組み込み `GaussianBlur` を 4 段、カスタムシェーダで σ 正規化つき勾配を合成。**RGBA16F 必須**（法線は符号付き） |
| P2 | 1/4 | P1 を R, R/2, R/4, R/8 でぼかしたもの | RG=V, B=φ | 重み ∝ σ で足して ≈1/r の長距離カーネルを作る |
| P3 | 1/4 | P2 | RGBA16F: dir.xy, amp, curl | swirl 回転・平滑化・コヒーレンス・距離減衰・curl・解像可能性を確定 |
| P4 | 等倍 | 元画像 + P3 | 最終色 | 流線を積分して変位サンプリング。力線/発光/色収差もここ |
| P5 | 等倍 | P4 + 放射場 | 最終色 | 端の色の引き伸ばし。**N 回の ping-pong** で 1 歩ずつ伝播させる |

- P1〜P3 が 1/4 解像度なので、`Radius` に関係なくコストがほぼ一定になる。
- P4 だけ等倍。場のテクスチャはバイリニアで拡大して読む（滑らかなので破綻しない）。

## 引き伸ばし（P5）は ping-pong で作る

1 画素ずつ長い流線を追う実装にしてはいけない。
鞍点の近くで隣接画素の流線が指数的に離れ、出力が櫛状の破線になる。
解像度を上げても消えない（画素のエイリアスではなく実構造のため）。

代わりに、RGBA16F 2 枚を ping-pong して 1 歩ずつ伝播させる。

- バッファ: `rgb` = 運んでいる色、`a` = 受け継いだ輪郭の強さ
- もう 1 枚 R16F で伝播距離を持つ（または a に詰める）
- 各パス: 1 歩上流（輪郭側）を 1 回サンプルし、
  `強さ - tie*距離` が今より大きければ色・強さ・距離を受け継ぐ
- パス数 = `flow_length / step_px`。1 パスの中身は
  テクスチャ 2 回読みと比較だけなので非常に軽い

この形は D2D でも素直に書け、per-pixel ループより速い。
塗る範囲の境界も伝播距離で決まるので滑らかになる。

## シェーダ側の注意

- **ステップ数**は px 基準で決める。`N = clamp(flowLength / stepPx, 8, maxSteps)`。
  プロトタイプで 1 ステップが 3px を超えると力線がジャギる事を確認済み。
  UI は Sa_chromablur と同じく「ステップ数（品質）」として露出する。
- **向きの半球揃え**（`dot(d, V) < 0` で反転）を入れないと、場の零線で流線が折り返して破綻する。
- **曲げ**は `turn = align * angle(d → V) + curvature * curl * h * k`。
  align は 0.65 固定でよい。ノイズではなく curl で曲げるのがこのエフェクトの肝。
- **引き伸ばしの場は変位の場と別**にする。端の色を引き出すには輪郭から外向き
  （φ の勾配の逆）でなければならず、Swirl の掛かった場だと流線が輪郭と平行に
  走って色を拾えない。変位が磁力線でも引き伸ばしは放射、という併用が要る。
- **力線描画（LIC）**は等倍で高周波ノイズが要る。
  - ノイズは**ソース座標に固定**する（スクリーン座標だと素材が動いた時に線が泳ぐ）。
  - `D2D1Turbulence` か、埋め込みノイズテクスチャを使う。
  - 前後両方向の LIC が必要なので、P4 とは別パスにしてブレンドした方が素直。
- 色収差は RGB で `flowLength` を変えるだけ。Sa_chromablur の色空間変換をそのまま挿せる。

## パラメータの公開

`ChromaticAberrationEffect.cs` と同じく `[Display]` + `Animation` で出す。

| UI 名 | 既定 | 範囲 |
| --- | --- | --- |
| 強さ | 60 | 0–200 |
| 影響範囲 | 150 | 8–600 (px) |
| 流線の長さ | 140 | 0–600 (px) |
| 曲がり | 100 | 0–500 |
| 回転(Swirl) | 0 | -100–100 |
| 引力/反発 | 0 | -100–100 |
| エッジ閾値 | 10 | 0–100 |
| 滑らかさ | 40 | 0–100 |
| 輪郭の細かさ | 50 | 0–100 |
| 力線を描く | 0 | 0–100 |
| 発光 | 0 | 0–100 |
| 色収差 | 0 | 0–100 |
| 元画像を残す | 0 | 0–100 |
| ステップ数 | 48 | 8–256 |

`Radius` / `Flow Length` は px なので、YMM4 側の拡大率に追従させるか素材基準にするかを決める必要がある。
プロトタイプは素材ピクセル基準。

## 動画にするときの注意

- ノイズ固定（上記）
- 場は素材の内容だけで決まるので、素材が静止していればフレーム間でちらつかない
- `Curvature` を上げると特異点（渦の中心）が現れる。素材が動くと特異点が動いて目立つので、
  動画では `Smoothness` をやや高め（0.5 前後）にするのが安全
